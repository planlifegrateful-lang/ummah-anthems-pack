# Product-pack release manifest

Before distributing a pack version:

- [ ] List every shipped file and its purpose.
- [ ] Record source and generation provenance.
- [ ] Confirm commercial-use terms for third-party platforms and media.
- [ ] Include required attribution and disclosures.
- [ ] Remove private data, credentials, and internal drafts.
- [ ] Validate all README links and sales claims.
- [ ] Record reviewer, version, and release date.

A repository license is not a substitute for verifying rights to included lyrics, prompts, audio, images, trademarks, or generated outputs.
